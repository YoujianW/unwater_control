# VOFA 库使用教程

工程已加入 `vofa.c/.h`。使用步骤为：**绑定 USART2 → 初始化 VOFA → 填入数据 → 发送**。

本教程先实现数据上传，不需要串口接收中断。

## 1. 使用前提

- `main()` 中已调用 `wk_usart2_init()`，完成 USART2 硬件初始化。
- 当前示例使用 115200 波特率、8 位数据位、无校验、1 位停止位。
- Keil 已加入 `vofa.c`、VOFA 头文件路径及 BSP USART 模块。
- USART2 应只有这个任务发送，避免 `printf()` 或其他任务混入数据帧。

`BSP_USART_Init()` 只绑定 BSP 句柄，不替代 `wk_usart2_init()` 的硬件配置。

## 2. 创建上传任务

下面的任务每 50ms 上传三个测试值：

```c
#include "vofa.h"
#include "at32l021_conf.h"
#include "FreeRTOS.h"
#include "task.h"

static BSP_USART_Handle_t vofa_uart;
static VofaHandle_t vofa_handle;

void vofa_Task_func(void *argument)
{
    (void)argument;

    /* main 中需要先完成 wk_usart2_init() */
    BSP_USART_Init(&vofa_uart, (void *)USART2);
    VOFA_Init(&vofa_handle, &vofa_uart,
              VOFA_FORMAT_JUSTFLOAT);

    for (;;) {
        float data[3] = {3.3f, 1.2f, 25.0f};

        VOFA_SendCustomData(&vofa_handle, data, 3,
                            VOFA_FORMAT_JUSTFLOAT);

        vTaskDelay(pdMS_TO_TICKS(50));
    }
}
```

`data[0]`、`data[1]`、`data[2]` 对应依次上传的三个通道。实际使用时，将常数替换为已经采集完成的电压等数据。

`VOFA_SendCustomData()` 直接发送数组，不修改句柄中的通道数据。参数 `count` 必须不超过数组实际元素数。

## 3. 在 APP 层创建任务

在 `app_task_create()` 中创建上传任务，并检查创建结果：

```c
BaseType_t result = xTaskCreate(vofa_Task_func,
                               "vofa",
                               256,  /* 1024 字节 */
                               NULL,
                               1,
                               NULL);
if (result != pdPASS) {
    /* 处理任务创建失败 */
}
```

调用处需要能看到 `vofa_Task_func()` 的声明。若任务实现在单独的 `.c` 文件中，应将该文件加入 Keil，并通过对应头文件提供声明。

这里的栈深度单位是 **32 位字**，`256` 对应 1024 字节。新增任务需要占用 FreeRTOS 堆，应检查返回值，避免任务因内存不足未创建却被忽略。

## 4. 上位机接收

电脑端选择对应串口、**115200、8N1 和 JustFloat 解析格式**，即可接收三个通道。

示例上传的是固定值，因此显示为三条固定数值的曲线。

JustFloat 每个通道发送 4 字节 float 数据，末尾追加 `00 00 80 7F`。普通串口助手按文本显示时可能呈现乱码，这是二进制数据的正常表现。

## 5. 另一种方式：使用通道接口

也可以不直接发送数组，而是先更新句柄中的通道数据，再统一发送：

```c
VOFA_SetChannelValue(&vofa_handle, 0, 3.3f);
VOFA_SetChannelValue(&vofa_handle, 1, 1.2f);
VOFA_SendData(&vofa_handle);
```

通道编号从 **0** 开始。`VOFA_SendData()` 使用初始化时指定的格式；`VOFA_SendCustomData()` 使用每次调用传入的格式。

两种发送方式按需要选择，不必在同一轮重复发送。

## 6. 使用范围

本教程只演示单任务上传，不接入命令解析或业务控制。当前 BSP USART 按字节加锁，因此需要避免多个发送者共享 USART2，尤其不能混入调试文本或声纳协议数据。

本文件仅提供使用教程，示例未自动加入任务源文件、任务创建函数或其他工程代码。
