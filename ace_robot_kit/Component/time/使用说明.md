# time 库使用说明

这个库的使用分为：**配置定时器 → 初始化 → 接入中断 → 读取时间。**

## ① 配置与硬件一致

在 `time_config.h` 中设置：

```c
#define TIME_TMR            TMR16
#define TIME_TMR_PERIOD     999U
#define TIME_TMR_PRESCALER  79U
#define TIME_TMR_CLOCK_HZ   80000000UL
```

这里的 80MHz 必须是实际的 **TMR16 输入时钟**。若配置确实如此，定时器每 1μs 计数一次，每 1ms 溢出。

## ② 初始化一次

在硬件初始化后、业务使用前调用：

```c
wk_tmr16_init();
time_init();
```

`time_init()` 只清零软件溢出计数，不配置或清零硬件定时器。不要在任务循环中反复调用。

## ③ 接入 TMR16 中断

```c
#include "time_core.h"

void TMR16_GLOBAL_IRQHandler(void)
{
    time_overflow_handler();
}
```

它内部会检查并清除溢出标志。你现有中断中的清标志代码需要统一处理，不能先清掉再调用它，否则无法累计时间。

## ④ 在任务中读取

例如统计两个操作之间的耗时：

```c
uint64_t start_us = time_get_us();

/* 执行操作 */

uint64_t elapsed_us = time_get_us() - start_us;
```

例如从某个业务开始时计满五分钟：

```c
void Example_Task(void *argument)
{
    uint32_t start_ms = time_get_ms();

    for (;;) {
        if ((uint32_t)(time_get_ms() - start_ms) >= 300000UL) {
            /* 五分钟已到 */
            /* 根据业务执行动作或退出计时 */
        }

        vTaskDelay(pdMS_TO_TICKS(100));
    }
}
```

这里记录开始时间再做差，可以实现“从当前时刻开始计时”，无需重新调用 `time_init()`。

## 延时接口

延时接口也可以使用：

```c
time_delay_us(10);  /* 忙等待约 10μs */
time_delay_ms(20);  /* FreeRTOS 任务中使用任务延时 */
```

普通任务延时继续使用 `vTaskDelay()` 即可。参考库存在前面提到的溢出读取窗口问题，微秒耗时示例只是接口用法，不能据此认为计时已经严格可靠。

具体来说，硬件定时器已经溢出、但溢出中断尚未处理时，软件溢出次数仍是旧值，此时读取时间可能暂时回退。

以上代码为使用示例。本次仅保存说明文档，未修改工程代码或接入初始化、中断和业务调用。
